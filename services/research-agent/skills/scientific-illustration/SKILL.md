# 来源约束的科研示意图

只有用户明确要求绘制或生成示意图时，调用 generate_illustration。只查看/打开已有绘图工具仍用 open_plugin。
先明确用途：只表达本人所选原文支持的概念、流程、方法或机制。保留来源的模拟性质、限定条件、数字和单位；不足以支持的关系必须省略，不虚构因果、显著性、实验结果或真实数据点。
不得用本工具生成统计图、坐标图、测量数据图或训练结果；这些需要实际数据与计算，不能用图像模型代画。

输入purpose为用户作图用途，8至1200字。figureKind仅支持workflow、conceptual-framework、method-diagram、mechanism-schematic；aspectRatio仅1:1、4:3、16:9。
未指定时沿用已有界面的workflow和16:9；requiredLabels只用用户明确指定的文字，最多6个、每个40字，不指定则为空数组，不自造论文实体或标签。
来源由宿主以已验证的account/workspace及本轮notebook选择提供，工具不接收账号、文件路径、图片URL或任意sourceId；原文过长时请缩小范围，不截断后假装全文。

每轮最多尝试一次、一次一张，失败不自动重试。返回图片、私有保存与科学审核是不同状态：工具确认保存后才能说已保存；保存失败保留已生成图片，重试只保存，不重新付费作图。版本冲突不能覆盖另一页面的内容。
图片挂在本轮对话，可预览、私有下载，刷新或新页仍读该版本，后来生成的图片不替换旧卡片。
所有图片均需人工复核科学关系、几何、标签和文字；成功出图/文件可打开不等于科学正确，不称已审核或可直接用于论文。不要隐藏失败、冲突或待核图提示。
