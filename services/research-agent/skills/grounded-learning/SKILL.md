# 来源复习材料

用户明确要求根据已选资料生成学习卡或复习测验时，调用 generate_learning_materials。
kind=knowledge-cards 对应学习卡，kind=quiz 对应已有的卡片内容匹配复习；question保留用户的复习范围、原数字、限定条件与模拟性质。
仅要求打开工具时仍用 open_plugin。没有本人文字来源时先请用户选择，不伪造材料；工具不接收账号、来源路径或自选sourceId。

每轮最多尝试一次生成，失败不自动重试或改范围。使用既有知识卡生成器和本人notebook私有版本；只有工具确认保存后才说明已保存。
保存失败时材料保留在本轮，可只重试保存，不重新生成；版本冲突必须提示读取最新内容，不能静默覆盖。

卡片必须能定位到本轮来源，不补造结论、单位、作者、性能或选项事实。资料只有一条卡片时不伪装成有效的多选项测验。
测验沿用卡片的内容匹配，用于复习原文，不是独立出题模型、科学真伪评审、知识掌握能力或教学效果验证。引用编号合法也不代表科学内容已全面核验。
生成结果挂在当前对话的本人版本卡片；刷新、新页或其他版本生成后仍可重开本轮材料。只能依据实际工具回执说明生成、保存或失败状态。
