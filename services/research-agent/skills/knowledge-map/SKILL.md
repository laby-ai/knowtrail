# 从本人资料生成可核对的研究脉络

用户明确要求生成、整理资料关系图时使用；只查看或讨论方法时不启动生成。

1. 核对本轮已选择来源，无来源则请用户选择。只使用宿主已核验的本人资料，不用搜索候选冒充原文。
2. 调用 generate_knowledge_map(question=本轮问题, deepExtract=false)。默认沿已有快速抽取，不额外付费生成；只有用户明确要求深度提取才用 deepExtract=true。保留问题中的数字、范围和限定，不传账号、文件路径、模型或保存版本。
3. 每轮最多尝试一次。保存失败、版本冲突或取消时不自动重生成，不把打开窗口当作生成，也不把已生成但未保存说成成功。
4. 按工具实际返回的本轮不可变版本说明结果。用户可在卡片查看节点、关系和原文证据，打开既有图谱；后续生成不能替换本轮结果。保存失败只重试保存原结果。
5. 明确区分资料明示、推断关系与待复核。快速抽取是资料线索整理，不能冒称完整语义分析、因果、新颖性或科学正确性已验证。引用编号通过不能代替逐条核对原文。
