# 账号信息与账号系统统一 — 2026-10-04

设置弹窗打开时通过 `/api/account/session` 携带当前 Bearer token 查询账号中心，账号页和安全页都使用同一份服务端返回的 member/tenant 数据，不再直接展示本地登录占位信息。

读取期间显示同步状态；账号中心返回 401 时提示登录失效并提供退出；其他失败提供重新加载。每次重新打开都会重新读取，确保姓名、邮箱、组织变化及时反映。百炼配置继续使用当前有效会话，不改动真实密钥。
