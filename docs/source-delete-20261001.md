# 文献库持久删除修复 — 2026-10-01

原因：旧 removePaper/deleteFolder 只更新浏览器状态；15 秒服务端同步会重新导入尚未删除的来源。

变更：新增带账号和文献本范围校验的批量 DELETE 接口，移除来源记录及其文本片段；单篇、批量和分组删除统一经过确认弹窗，服务端成功后更新本地状态。取消选择保留为独立操作。删除期间丢弃旧同步结果；正在处理的来源返回 409，避免任务写回。

验证：隔离临时数据存储上的 scripts/test-source-deletion.ts 通过（持久化、检索排除、跨账号/跨文献本、批量原子性、参数和登录校验、重复删除）。ESLint、Next.js 生产构建及服务端 tsup 构建通过。

真实浏览器验收：独立 5099 预览服务及临时来源库中创建三条测试来源，取消确认保持资料；批量删除两条，服务端只剩一条，自动同步和刷新后未恢复；右键单篇删除最后一条，刷新后服务端列表为空。未删除线上用户资料。

范围：删除文献库来源和索引引用；原始上传文件的物理垃圾回收不在本次修复范围内。
