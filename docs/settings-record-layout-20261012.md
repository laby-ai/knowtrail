## 行为

设置沿用统一齿轮入口，点击打开账号、安全、百炼页签；账号信息继续从账号系统读取。调整弹窗留白和页签高度，未新增账号或模型配置接口。

研究记录弹窗增加明确分区和 24px 分区间距。阶段名称和保存数量分行；宽屏下编辑区与已保存记录分栏，窄屏按单列显示。输入区加高，正文行距 28px，关联来源、统计方法、执行编号和文件摘要分开排版。归档按钮分行排列，空记录显示真实空状态。

保留记录保存、当前对话整理、云端读取确认、清除对话确认、JSON 导出、关联来源和带入学术写作的原有行为。

## 验收

- 服务器 `pnpm exec eslint` 检查两个变更组件、`pnpm exec tsc --noEmit`、Next.js webpack 生产构建和服务器 tsup 构建通过。
- 隔离账号和存储目录的浏览器验收通过：研究记录通过实际 API 保存和读取，内容中 1.5% 保持原样；读取云端对话后，选中记录可以带入学术写作。
