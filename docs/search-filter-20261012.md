# 文献检索与发现信源主题筛选

功能版本 `f2387aa`，分支 `codex/lingbi-pdf-remaining-20261010`；发布 `/opt/knowtrail/releases/lingbi-search-filter-20261012`。

两处服务端复用 search-topic-relevance。普通主题查询须覆盖全部核心词；标题与摘要/检索片段提供主题依据，不允许仅靠期刊名、作者名或网页导航词保留结果。中文按词切分并去掉泛词；英文按完整词边界匹配，防止 AI 命中 rainfall/Spain。有限的常见科研中英别称支持 AI、机器学习、多模态、大模型、量子传感器等，不宣称覆盖全部语义同义词。

发现信源仅在没有检索片段时以最多 6000 字正文作为补充，返回过滤后的数量，并保留 providerTotal 与筛选统计。文献服务保持真实元数据签名，年份约束排除未知年份，DOI/arXiv 标识符检索精确匹配。没有修改已入库文献或私人记录。

特殊布尔、引号或字段语法交由搜索源处理，标记待核验，避免把 OR 擅自改为 AND。无核心词的查询也保留来源结果并提示核验。筛选是可复现的词语覆盖初筛，不是全文语义判定、来源真实性或学术质量核验；相关文献若使用未收录别称仍可能漏检。

验收：ESLint、TypeScript 与 Next.js/tsup 构建通过，保留已有 ingestion-store 动态依赖构建警告。三组回归脚本通过，覆盖 AI 词边界、缺失核心词、中英术语、中文泛词、年份、标识符、仅作者名/期刊名命中、导航词干扰及签名保留。服务测试编译产物位于 /tmp，第一次执行缺少 zod 的解析路径，设置 NODE_PATH 后通过。

隔离的真实路由/服务接口验收通过：上游三条受控候选，文献接口只返回一条，发现信源只返回一条并报告过滤两条；全不相关查询返回零条及 all-irrelevant。上游与账号为隔离 fixture，检索接口自身未 mock；签名密钥在 QA 单独覆盖，测试候选不能在生产入库。

Tabbit 浏览器注册不可用，未重启用户浏览器；此次没有声称完成浏览器视觉或窄屏验收。接口检查替代本轮界面交互检查，页面布局未修改。
