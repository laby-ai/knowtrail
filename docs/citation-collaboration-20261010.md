# 期刊引用与多人协作交付记录

本轮完善灵笔的期刊引用、解析全文引证检查和同一组织内共享研究文档。接口使用账号系统验证的成员与组织，不信任浏览器提交的姓名、成员标识或文献所有者。

## 用户操作

学术写作生成草稿后，在题录区域选择 IEEE、APA 7、Vancouver/NLM、GB/T 7714 顺序编码 2015 或 2025、Nature、Science、PLOS、Cell，点击“应用期刊引用格式”。真实 citeproc 处理器按已引用来源生成正文编号或作者年份及参考文献，去除重复来源，保留斜体和上标。缺少题录字段时显示警告，不补造信息。选择“稿件正文”后 Word 和 LaTeX 只导出正文及格式化参考文献；核验模式保留证据附录。格式及许可版本见 `src/assets/csl/PROVENANCE.md`。这不代表满足各期刊全部投稿要求。

“检查原文匹配”搜索所选来源全部已保存文本片段，检查引文片段、页码、片段位置及正文引用，提供解析文本摘要指纹。“主张语义评审”使用当前真实账号绑定的百炼文本模型，要求模型返回原文证据并二次检查证据是否确实存在。没有配置、账号不匹配或调用失败时，保留原文检查结果并显示原因。原文出现同一片段不等于正文主张已获得支持。

三分栏顶部“课题组共享”或草稿中的“保存并共享草稿”可创建项目研究文档。所有者按同一组织成员邮箱授予编辑或查看权限。独立账号可共同编辑正文、查看在线成员与光标位置、提交带原文锚点的批注、解决批注、保存快照及恢复版本。正文修改使用 Yjs 合并，每两秒同步；自动每三十秒留存快照，最近二十个版本可查看和恢复。网络失败保留未同步草稿，并提供按账号、文献本和文档隔离的本地备份。

所有者和编辑成员可从各自当前文献本贡献文献，共同维护项目共享来源。服务端保留每份来源真实所有者和文献本范围。移出共享仅取消项目共享，原文件仍属于上传者。撤销成员权限后拒绝后续编辑、原文读取和原文件下载；已经取得的本地副本无法远程收回。

## 工程边界

- 原文检查覆盖持久化的解析文本，不声明扫描图片、未提取页或完整原始 PDF 都已核验。语义评审最多八条主张，选取有限实际原文片段，四十五秒限时；结果是需人工复核的模型意见。
- 正文引用格式针对草稿明确声明的证据编号；没有书目事实时保留缺失提示。复杂手写引用应由作者检查。
- 协作采用两秒 HTTP 同步，不是毫秒级 WebSocket。共享研究正文、批注、历史及文献授权，不同步私人聊天，也不开放跨组织邀请。
- 文档正文最多十万字符，CRDT 状态上限一 MB，来源最多一百份，组织文件上限二十 MB。当前存储适用于单服务进程；多实例部署前应迁移事务数据库与共享在线状态。
- 格式 XML 固定上游版本，保留许可；界面有 citeproc 和 CSL 署名。导出只插入安全文本与允许的样式，不执行上游 HTML。

## 验证

服务器类型检查、相关 ESLint、生产构建和引用架构边界检查通过。测试使用独立临时存储及明确的测试身份，不改用户资料。

实际接口测试覆盖九种 CSL 格式、作者排序、重复来源、斜体与上标、Word/LaTeX 内容及转义；原文精确匹配、错误位置、文本指纹变化、伪造模型证据拒绝；两个独立 Yjs 客户端的并发编辑、重放、恶意更新拒绝、批注和历史恢复；多所有者共享来源、编辑贡献、查看者禁写、跨账号拒绝和撤权后的原文件拒绝；账号模型及组织计费路径校验。

浏览器通过独立来源域的两个账号验证引用格式应用、解析原文检查、双方编辑合并、批注传播和撤权后编辑器锁定。测试登录与写作生成输入为隔离夹具，研究文档、引用及协作请求使用真实候选版本接口。尚未使用真实用户额度进行生产语义模型质量评测；LaTeX 已验证导出源码，未宣称通过 XeLaTeX 编译。

学术语料微调按用户决定暂缓。其他期刊的完整投稿模板、跨组织邀请及多服务进程部署不计作本轮已完成项。
