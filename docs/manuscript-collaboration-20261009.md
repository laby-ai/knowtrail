# 科研写作与课题组共享交付记录

日期：2026-10-09。对应科研标签 PDF 的 R02/R07/R08/R09/R10/R11/R20/R23。

## 用户入口

- 学术写作：生成章节后点击证据上标，查看来源片段、页码及片段位置；可编辑段落。编辑后标记为待核验证据，原主张映射不能当作已更新。
- 论文排版与导出：下载真实 DOCX 和 LaTeX 文件，选择通用 A4 单栏/双栏，保留中文、原文摘录、证据编号和作者核验清单；网页预览用于检查结构。
- 相关期刊与官方模板：按关键词实时检索 Crossref 前 40 条期刊论文，显示真实刊名、出版社、ISSN 和 DOI，列出样本命中分布。官方 IEEE 模板选择器为外部官方入口，通用导出不冒充官方投稿模板。
- 课题组共享：工作区顶部可创建研究文档/实验日志；生成草稿也可保存并共享。同一账号组织内以邮箱赋予查看/编辑权限；原文件须由所有者另行勾选共享。

## 工程边界

所有协作请求使用账号系统返回的成员 ID、邮箱及组织 ID。查看者不能保存，编辑者不能授权成员或共享来源；来源共享须属于所有者的文献本。每次原文读取/下载均重新校验成员及来源授权，撤销后拒绝后续访问。接口不暴露原文件的内部存储键。

保存检查 revision，旧版本返回 409，不覆盖其他人的修改。原文、成员及来源授权修改保留最近 20 个版本；单份内容上限 100000 字符，个人最多 200 份文档，组织 JSON 上限 20 MB。存储位于 SOURCE_STORE_PATH 同级 research-documents，可通过 RESEARCH_DOCUMENT_STORE_PATH 覆盖。当前适用于单服务进程部署，多实例需要数据库事务替换进程内写队列。

## 验收

- test-manuscript-collaboration.ts：DOCX 格式、单/双栏、中文及特殊字符、引用上标、LaTeX 转义；所有者/查看者/编辑者、组织隔离、同版本并发冲突及撤权。
- test-shared-research-sources.ts：真实原文件字节、片段原文、显式授权、跨所有者拒绝、仅所有者授权来源、移除来源和撤销成员权限后拒绝访问。
- 生产构建、类型检查及新增模块 ESLint；浏览器使用隔离身份及写作结果回放，验证证据卡、导出二进制、双栏预览；共享文档保存和权限设置访问真实预发布接口及独立临时存储。
- DOCX 单栏与双栏验收文件均由 render_docx.py 调用 LibreOffice 渲染，逐页检查中文、符号与编号。LaTeX 已验证源文件及转义，尚未安装 TeX 发行版验证编译。
- Crossref 从部署服务器返回真实期刊文章元数据。该接口的检索匹配不是接收概率、影响因子或已完成的选刊评估。

## 2026-10-09 期刊 Word 模板进展

- 新增 IEEE Access 官方 Word 2024 样式套用，以及本地 DOCX 模板导入。提取实际段落样式、纸张尺寸、页边距和单/双栏；可映射标题、正文、章节标题样式。
- 导出创建新文档，只使用模板的样式、主题、编号及安全的页面设置，不复制示例作者、DOI、页眉页脚、宏或嵌入文件。通用 LaTeX 导出保持独立，目前不是出版社 LaTeX 模板套版。
- 官方模板来源固定，服务端缓存与下载均校验 SHA-256。所有模板接口仍要求真实账号验证。本地模板只在浏览器解析，不上传服务端。限制文件、XML 解压大小和条目数量，拒绝 DTD/实体声明及错误命名空间。
- 官方模板验收：PaperTitle/PARA 样式、实际纸张尺寸、双栏正文与跨栏标题、原示例正文移除、英文核验标签；真实 DOCX 经 LibreOffice 渲染，逐页检查无截断或乱码。
- 前述统计执行、科研偏好及稿件协作分支已通过服务器现有 Git 授权推送到 laby-ai/knowtrail；本轮代码使用独立期刊模板分支。

仍需完善完整规范书目、其他期刊精确套版、整本文献本共同维护及实时共同编辑。官方样式套用不代表已经满足期刊全部投稿条件。
