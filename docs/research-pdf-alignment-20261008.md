## 发布顺序与验收

1. 研究偏好及科研界面基础（R16/17/21/24/25/26/27/28）：账号隔离、真实保存接口、首次选择、设置可修改、默认值只在用户未主动选择时应用。
2. 证据层（R02/03/04/12/13/14/19/20）：真实文献与段落 ID、来源/证据范围、引用高亮和矩阵核验；未获取到的元数据留空。
3. 数据执行（R05/06/22）：隔离执行、资源限制、真实结果、分析脚本、统计假设、图表与 Results；不得把生成方案标成已执行。
4. 写作交付（R01/07/08/09/23）：章节与引用关联、DOCX/LaTeX、期刊匹配和双栏预览。
5. 协作沉淀（R10/11/18）：服务端日志/对话、课题组 ACL、并发版本、审计记录、真实阶段事件。

每批独立分支、提交、测试、发布及回滚。当前 GitHub 推送权限 403 必须如实记录，不能标为已推送。

## 非功能事项与外部依赖

PDF 的学术语料微调需真实语料、训练平台和评估集；尚无材料时不宣称完成。学术 KOL 合作、营销案例与“节省 15 小时”需要另行授权、实测或真实合作记录，不通过替换界面文案假装实现。影响因子来源与期刊模板需确认真实来源；不填示例数值。

用户已确认暂无训练语料与模型平台，微调暂缓，继续其他产品功能。Vancouver 基础输出参考 [NLM 引用指南](https://www.nlm.nih.gov/bsd/uniform_requirements.html?lang=en)；未提供期刊缩写时保留真实期刊名称，不猜造缩写或补造缺失字段。

用户已确认暂无 JCR 等影响因子授权数据。影响因子显示“未取得，暂无授权数据”，不使用示例数值；继续其他产品功能。
